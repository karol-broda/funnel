The funnel server exposes a REST API at `/api/v1`. All endpoints except health and info require authentication via `Authorization: Bearer <api_key>`.

Browse the API reference by section:

- [Server](/docs/reference/server-api/server) - Health check and server info
- [Tunnels](/docs/reference/server-api/tunnels) - Tunnel management
- [API Keys](/docs/reference/server-api/api-keys) - API key management
- [Profile](/docs/reference/server-api/profile) - Current user profile, accounts, sessions
- [Users](/docs/reference/server-api/users) - User management (admin)
- [Teams](/docs/reference/server-api/teams) - Team management

The interactive API reference is also available at `/api/v1/scalar` on a running server.
